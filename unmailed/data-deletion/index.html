이 문서는 VIIXI Labs가 운영하는 부치지 못한 편지(Unmailed)의 사용자 데이터 삭제 방법과 삭제 요청 절차를 안내합니다.

VIIXI Labs는 이용자가 자신이 작성한 편지와 관련 데이터를 관리할 수 있도록 앱 내 삭제 기능과 이메일을 통한 데이터 삭제 요청 방법을 제공합니다.

1. 앱 내에서 편지 삭제하기

이용자는 부치지 못한 편지 앱에서 자신이 작성한 편지를 직접 삭제할 수 있습니다.

  1. 부치지 못한 편지 앱을 실행합니다.
  2. 하단 메뉴에서 '내 편지'로 이동합니다.
  3. 삭제할 편지를 선택합니다.
  4. 삭제 기능을 선택하고 삭제를 확인합니다.

삭제된 편지는 일반 사용자에게 더 이상 표시되지 않습니다. 관련 데이터의 실제 삭제 및 보관 범위는 서비스 처리 방식과 관련 법령에 따릅니다.

2. 추가 데이터 삭제 요청

앱에서 직접 삭제할 수 없는 데이터나 익명 사용자 식별정보 등의 삭제를 원하는 경우, 아래 이메일을 통해 요청할 수 있습니다.

요청 이메일: la.pharos711@gmail.com

이메일 제목에 '부치지 못한 편지 데이터 삭제 요청'을 기재하고 삭제를 원하는 데이터의 종류를 알려주세요.

요청을 처리하기 위해 필요한 경우 해당 데이터에 대한 요청자의 권한을 확인할 수 있습니다. 불필요한 개인정보나 타인의 개인정보는 이메일에 포함하지 마시기 바랍니다.

3. 삭제 요청 대상 데이터

삭제 요청 대상에는 다음 정보가 포함될 수 있습니다.

  • 이용자가 작성한 편지 및 관련 정보
  • 편지에 입력된 수신인 이름 및 생년월일
  • 편지 내용, 힌트 및 작성·도착 예정 시점
  • Firebase 익명 사용자 식별정보
  • 기타 해당 이용자와 관련하여 보관 중인 정보

4. 데이터 삭제 및 보관

데이터 삭제 요청이 접수되면 요청 내용과 처리 권한을 확인한 후 삭제 가능한 정보를 처리합니다.

다만 관련 법령에 따라 보관이 필요한 정보나 정당한 보관 근거가 있는 데이터는 해당 목적과 기간 동안 별도로 보관될 수 있습니다.

삭제되지 않는 정보가 있는 경우 관련 근거와 보관 기간을 확인하여 요청자에게 안내합니다.

5. 앱 삭제와 데이터 삭제의 차이

앱을 기기에서 제거하는 것만으로 서버에 저장된 편지 및 관련 데이터가 모두 삭제되는 것은 아닙니다.

데이터 삭제를 원하는 경우 앱 내 편지 삭제 기능을 사용하거나 본 페이지에 안내된 이메일로 요청해 주세요.
